E-Library Management Dashboard

This project is developed using Python, Pandas, Matplotlib, and Seaborn. It loads library transaction data from a CSV file, performs data analysis, generates reports, and visualizes insights through various charts.

Features:

• Load and clean library transaction data
• Remove duplicate records
• Generate statistics and reports
• Filter data by genre
• Display visualizations including:
  - Bar Chart
   
  - Line Chart
   
  - Pie Chart
   
  - Heatmap

Technologies Used:

• Python

• Pandas

• Matplotlib

• Seaborn

• Object-Oriented Programming (OOP)

Required CSV Columns:
• Transaction ID 

• Date

• User ID

• Book Title

• Genre

• Borrowing Duration (Days)

How to Run:
1. Install required libraries:
   pip install pandas matplotlib seaborn

2. Run the program:
   python library_dashboards.py


Purpose:
Educational and practical implementation of data analysis, visualization, and OOP concepts in Python.
